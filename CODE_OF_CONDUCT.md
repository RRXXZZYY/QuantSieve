# Code of Conduct

QuantSieve is an evidence-first project. We want technical disagreement to be direct, reproducible, and respectful.

## Expected behavior

- Discuss ideas and evidence rather than attacking people.
- State assumptions, uncertainty, and conflicts of interest.
- Do not fabricate market data, results, benchmarks, credentials, or project history.
- Protect personal information, credentials, account details, positions, and non-public data.
- Give reviewers enough context to reproduce a claim without exposing sensitive material.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, sustained disruption, impersonation, and knowingly deceptive claims are not accepted in project spaces.

## Scope and enforcement

This policy applies to repository discussions, pull requests, issues, and other spaces where someone represents the project. Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when behavior violates this policy.

For an immediate safety concern, use GitHub blocking and abuse-reporting tools. Do not put private or security-sensitive evidence in a public issue; use the private process in [SECURITY.md](SECURITY.md) or an already established private channel.

Enforcement decisions should be proportionate, documented where safe, and focused on protecting participants and the project.
